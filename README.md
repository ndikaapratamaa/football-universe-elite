# ⚽ Football Universe Elite

**Semua tentang sepak bola, dalam satu tempat.**

Football Universe Elite adalah website untuk para penggemar sepak bola: berita, statistik, kompetisi, kuis, mini game, dan leaderboard dalam satu tampilan premium bergaya gelap.

> 🚧 **Status:** masih dalam pengembangan. Kick-off sebentar lagi.

---

## ✨ Sorotan

- **Layar sambutan** yang menyambut pengunjung sebelum masuk ke beranda
- **Beranda lengkap**: Live Match Ticker, Player Spotlight, Daily Challenge, Competitions, News, Leaderboard, Hall of Fame, dan banyak lagi
- **Tampilan glassmorphism** dengan tema gelap dan pencahayaan ambient ala stadion malam
- **Animasi halus** di setiap bagian, dari hero sampai footer
- **Responsif**, nyaman dibuka di HP maupun komputer

## 🛠️ Dibangun dengan

| | |
|---|---|
| Framework | Next.js 15 (App Router) dan React 19 |
| Bahasa | TypeScript |
| Styling | Tailwind CSS |
| Animasi | Framer Motion |
| Ikon | Lucide React |
| Komponen | Radix UI, next-themes |
| Hosting | Vercel |
